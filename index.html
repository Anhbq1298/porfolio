Research · Vietnam

Optimal temporary facilities' positions in construction site layout using a genetic algorithm

Tối ưu hóa vị trí phụ trình trong bình đồ công trường bằng thuật toán di truyền

Phạm Vũ Hồng Sơn, Phạm Minh Nhân · Tạp chí Xây Dựng (Vietnam Construction Journal), 10/2018, pp. 167–171

My contribution: developed the VBA program and ran the case study (not a listed author).

Abstract. In building construction, a site layout provides information about position, size and quantities of the main buildings and temporary facilities which support the construction project. A well-planned site layout is important to any building project in reducing costs, improving productivity and safety. This is a complicated problem because of the diversity in properties of facilities and many external factors. With the robust development of computer technology, much research has been done to create models that can draw site layouts automatically. In this paper, a model based on a genetic algorithm with a "competition in population" method has been developed in order to solve the construction site layout problem.

Keywords: construction site layout optimization, temporary facilities, genetic algorithm, artificial intelligence (AI).

Tools & R&D

Software I've built to remove manual steps from structural design — from award-winning internal tools to open web apps.

C# · .NET 8 · WPF · own FEM solver

Mcotis

Parametric study and design of cable-supported and tied-arch transfer structures.

  • Study engine: every loading × truss depth × cable pretension candidate is generated and analysed automatically.
  • Solver: in-house FEM with tension-only cables, benchmarked against SAP2000; SAP2000 / ETABS kept only for import and export.
  • Design: steel, CFT, encased and mega composite columns, with column optimisation over section ranges.
  • Cost: material quantity take-off and estimated cost per candidate, so options are compared on tonnage and price.
New · .NET 8 · WPF · ETABS API

Bridger

Moves parts of one ETABS model into another — geometry, names, assignments and definitions intact — with every value verified against the target model.

TypeScript · React · web

MCalcCanvas

A Mathcad Prime–style calculation workspace in the browser.

  • Free canvas: equations placed anywhere on A4 pages with an engineering grid.
  • Live engine: unit-aware evaluation — change an input and every dependent result updates.
  • Templates: RC beams and columns (EC2), steel beams and beam-columns (EC3), composite design (EC4).
  • Reports: vector PDF calculation sheets with title block, outline and parameter panel.

TypeScript · web · MCalcCanvas engine

mCompositeBeamDesign

Composite beam design to EN 1994-1-1 in the browser.

  • Design: simply supported composite beams on solid slab or profiled deck, uniform or tapered sections, construction and composite stages.
  • Checks: bending, shear, LTB, shear connection, web under point loads, transverse slab reinforcement and deflection — each with its clause and utilisation.
  • Open report: the full calculation opens in MCalcCanvas, where it can be customised, reviewed and exported to PDF.

TypeScript · web

MBColumn Lite

Browser version of MBColumn for rectangular RC columns — Eurocode 2 fibre PMM check.

  • Section editor: draw and drag bars on a grid canvas, or edit coordinates in a table; set bars by face.
  • Check: fibre-based 3D PMM surface for multiple load cases, with P–M and Mx–My diagrams and optional EC2 §5.8 slenderness. Solves in the browser in seconds.
  • Open report: results export to a report that opens in MCalcCanvas for customising and review.

C# · .NET 8 · WPF

MBColumn

Reinforced-concrete column design, PMM checking and reporting.

  • Sections: rectangular, circular and irregular polygon sections with full rebar modelling.
  • Checks: PM, Mx–My and 3D PMM interaction surfaces; shear check; EC2 slenderness workflow.
  • Codes: ACI 318 and Eurocode 2 through a pluggable design-code layer.
  • Workflow: ETABS force import, multiple load cases, project save/open and engineering report generation. The same solver also powers a PMM check inside AutoCAD.

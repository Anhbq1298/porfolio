Research · Vietnam

Optimal temporary facilities' positions in construction site layout using a genetic algorithm

Tối ưu hóa vị trí phụ trình trong bình đồ công trường bằng thuật toán di truyền

Phạm Vũ Hồng Sơn, Phạm Minh Nhân · Tạp chí Xây Dựng (Vietnam Construction Journal), 10/2018, pp. 167–171

My contribution: developed the VBA program and ran the case study (not a listed author).

Abstract. In building construction, a site layout provides information about position, size and quantities of the main buildings and temporary facilities which support the construction project. A well-planned site layout is important to any building project in reducing costs, improving productivity and safety. This is a complicated problem because of the diversity in properties of facilities and many external factors. With the robust development of computer technology, much research has been done to create models that can draw site layouts automatically. In this paper, a model based on a genetic algorithm with a "competition in population" method has been developed in order to solve the construction site layout problem.

Keywords: construction site layout optimization, temporary facilities, genetic algorithm, artificial intelligence (AI).

Technical scope

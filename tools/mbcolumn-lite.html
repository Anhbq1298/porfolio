Problem

Preset symmetric reinforcement patterns can misrepresent columns with uneven, non-typical bar placement. The engineer needs to see how each individual bar position changes the interaction capacity under axial load and biaxial moments.

Proposed solution

Define each reinforcing bar by its actual coordinates in the section, then solve concrete-and-steel equilibrium using a fibre-section model. Rebuild the PMM interaction surface whenever the reinforcement arrangement is changed.

Engineering methodology

  • Flexible reinforcement editor. Input or drag individual bar coordinates rather than relying on preset symmetric arrangements.
  • Fibre discretisation. Represent concrete fibres and discrete steel bars using their actual positions.
  • General PMM solution. Calculate axial and biaxial moment capacity for the selected section and reinforcement layout.
  • Immediate feedback. Refresh the 3D PMM surface, demand/capacity checks and associated 2D diagrams when reinforcement positions change.
  • Report. Prepare a reviewable calculation that can be opened in MCalcCanvas.

Engineering outcome

A flexible reinforcement-layout design tool: the PMM surface reflects the actual bar coordinates, allowing engineers to investigate non-typical arrangements instead of forcing them into symmetrical templates.

Technical implementation

  • TypeScript web app; the solver runs in a background worker so the interface stays responsive.
  • Interactive 3D surface with load-case points, governing ray and capacity contours.

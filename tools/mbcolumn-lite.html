Problem

Checking biaxially loaded columns needs the full P–Mx–My capacity surface. Commercial tools are licensed per seat, and quick spreadsheets usually simplify biaxial bending.

How it works

Methodology

  • Section editor. Draw and drag bars on a grid canvas, edit coordinates in a table, or set bars by face.
  • Fibre analysis. The section is meshed into concrete fibres and bars; the solver builds the 3D PMM surface.
  • Checks. Multiple load cases with demand/capacity ratios, P–M and Mx–My diagrams, and optional EC2 §5.8 slenderness.
  • Report. Results export to a report that opens in MCalcCanvas.

Result

A free, browser-based biaxial column check that solves in seconds and produces a reviewable report.

Technical implementation

  • TypeScript web app; the solver runs in a background worker so the interface stays responsive.
  • Interactive 3D surface with load-case points, governing ray and capacity contours.

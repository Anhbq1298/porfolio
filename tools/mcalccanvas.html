Problem

Engineers need calculation reports that are clear enough to check and present, but paid software and opaque spreadsheets can make formula review, template reuse and report production unnecessarily difficult.

Solution

MCalcCanvas turns engineering mathematics into a readable, editable calculation canvas. The engineer manages assumptions and inputs; the platform evaluates formulas, exposes dependencies and turns the results into an organised, print-ready report.

Platform vision — templates, APIs and AI

The longer-term goal is a platform where any engineer can create, reuse and share calculation templates without depending on proprietary authoring software.

A documented platform API is intended to expose the formula engine, templates and document structure so an AI assistant can generate or modify expressions using the application's actual functions and conventions, rather than inventing unsupported syntax. The engineer remains responsible for selecting inputs, checking assumptions, reviewing calculations and approving the report for printing.

Current foundation: an interactive worksheet, unit-aware evaluation, editable templates and reporting. Development vision: a broader template ecosystem and API-connected AI authoring.

Engineering methodology

  • Transparent calculations. Place formulas, substituted numbers, units, diagrams and explanatory text together on a page.
  • Unit-aware engine. Editing an input updates its dependent expressions and checks.
  • Reusable templates. Build personal calculation sheets and edit EC2, EC3 and EC4 design examples.
  • Professional output. Produce an editable calculation report with clear document control and PDF export.

Engineering outcome

A free calculation workspace designed to make engineering mathematics easier to read, audit and communicate. Engineers keep control over assumptions and inputs, review the results and produce the final report.

Technical implementation

  • React + TypeScript with a custom canvas engine and math input.
  • Unit-aware evaluation engine; worksheets autosave in the browser.
  • Unit tests for the engine and serializer; browser acceptance tests with Playwright.

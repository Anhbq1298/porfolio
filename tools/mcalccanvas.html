MCalcCanvas

A browser-based engineering calculation platform combining unit-aware equations, structural design templates and editable technical reports.

Problem

Engineering calculations are usually written in spreadsheets, which hide the equations, or in desktop math tools that are licensed per seat. Reviewers need to see the formula, the units and the result together.

How it works

Methodology

  • Free canvas. Equations and text are placed anywhere on A4 pages with an engineering grid, like a hand calculation.
  • Live, unit-aware engine. Variables carry units; changing an input updates every dependent result.
  • Templates. RC beams and columns (EC2), steel beams and beam-columns (EC3) and composite beams (EC4).
  • Reports. Title block, outline and parameter panel, exported as vector PDF.

Result

Calculations that read like hand calcs but recalculate like software, shareable as a link and exportable as a clean PDF report. MCalcCanvas also opens the reports produced by mCompositeBeamDesign and MBColumn Lite for customising and review.

Technical implementation

  • React + TypeScript with a custom canvas engine and math input.
  • Unit-aware evaluation engine; worksheets autosave in the browser.
  • Unit tests for the engine and serializer; browser acceptance tests with Playwright.

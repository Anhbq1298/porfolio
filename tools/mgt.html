Problem

Rebuilding a changing parametric Rhino design in ETABS or SAP2000 introduces repeated modelling work and opportunities for geometry, loading and assignment inconsistencies.

Proposed solution

Connect Grasshopper definitions to CSI analysis models through reusable API components so engineers can translate geometry, assign structural properties, manage loads and query results without repeated manual rebuilding.

Engineering methodology

  • Geometry link. Transfer Rhino and Grasshopper geometry to analytical points, frames and shells.
  • CSI component library. Wrap ETABS and SAP2000 API operations for materials, sections, load cases and object assignments.
  • Parametric iteration. Update structural configurations as the geometry changes.
  • Supporting workflows. Apply Grasshopper data-tree processing and tributary-area studies where appropriate.

Engineering outcome

Engineering geometry and structural analysis remain connected through a repeatable parametric workflow, reducing duplicated modelling and making design iterations easier to audit.

Technical implementation

  • Grasshopper 8 plugin in C#, organised by component family (units, materials, loadings, points, frames, shells, cables, utilities).
  • Python 3 components for data-tree processing.
  • Compatibility and domain tests; example definitions shipped with the plugin.
